# Заметки для отчёта

Сюда по ходу работы складываются факты, цифры, скриншоты и решения, из которых потом
собирается пояснительная записка по ГОСТ. Формат свободный, главное — не терять контекст.

## Этап 0. Подготовка окружения

- Репозиторий: монорепо `backend/`, `frontend/`, `deploy/`, `docs/`.
- Все текстовые файлы хранятся с LF (`.gitattributes`): конфиги и скрипты исполняются в Linux.
- Скрипт первичной настройки VPS: `deploy/scripts/bootstrap-vps.sh`
  (Docker, пользователь `deploy`, ufw 22/80/443, swap).
- Домен: бесплатный поддомен DuckDNS (обоснование: TLS → HTTP/2 → SSE без лимита соединений).
